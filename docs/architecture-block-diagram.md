═══════════════════════════════════════════════════════════════════════════════
                           Data Flow
═══════════════════════════════════════════════════════════════════════════════

  Audio In ──► STT ──► Text ──► MT ──► Translated Text ──► TTS ──► Audio Out

  Each stage:
  • Implements FrameProcessor trait
  • Receives Frame via inbound channel
  • Sends Frame via outbound channel
  • Observers tap into the stream (read-only)
