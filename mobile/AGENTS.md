# Working in mobile

mobile is RiverVoice's calling client: real-time voice AI translation on live
phone calls. A user configures an "agent" — input/output language, tone,
voice — then places a call through it, over WebRTC (via ferry) or bridged to
a real phone call over Twilio. The agent translates both directions live,
speech in, translated speech out, low enough latency to hold an actual
conversation. See the root [README](../README.md) for the full system shape.
